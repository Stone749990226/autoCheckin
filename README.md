# Helper

个人使用的 Kotlin 原生 Android 工具（最低 Android 10 / API 29，针对 ColorOS 12.1 开发）。它按两个可配置时段定时唤醒屏幕、启动指定应用、读取界面提示并记录结果，随后锁屏；两个时段可分别启停和改时间。

## 构建

固定 AGP 8.6.1、Gradle 8.7、Kotlin 2.0.21，编译/目标 SDK 35。用 JDK 17，不要用系统 Java 19 或 Studio 自带 JDK 25。

```powershell
.\scripts\build.ps1                      # 找不到 JDK 时加 -JdkPath
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

`local.properties` 指向本机 SDK，不提交。

## 首次设置

| 设置 | 用途 |
| --- | --- |
| 精确闹钟 | Android 12+ 需授权“闹钟和提醒” |
| 通知 | 运行状态与停止按钮，渠道为 `General` |
| 电池优化豁免 | 减少待机限制 |
| 无障碍服务 | 启用 `Helper`，界面显示“已连接” |
| 设备管理员 | 仅用于结束后锁屏 |

ColorOS 还需：应用管理里允许自启动、关联启动、后台弹出界面；电池耗电管理不限制后台；最近任务里锁定本应用；关闭密码类安全锁屏。荣耀/华为需在“应用启动管理”里关闭自动管理并允许自启动、关联启动、后台活动。权限缺失时界面会阻止启用任务，运行前也会重新检查。

## 使用

- “启用每日任务”是总开关，下面两个时段可分别启停；两个时段至少间隔 15 分钟（4 轮约 11.5 分钟）。
- “测试启动应用”只打开目标应用并写日志，不监测结果；“测试完整流程”会完整跑一次并在结束后锁屏。
- 完整流程 4 轮、每 3 分钟一轮、每轮观察 150 秒；第 2 轮失败后清理并重启目标应用；识别到提示立即结束，4 轮都没有则记未确认。第二个时段的 4 轮都未确认且未超过“设定时间 + 60 分钟”时，追加 1 轮。
- 结果：`SUCCESS`（读到匹配提示）、`UNCONFIRMED`（需人工核对）、`ERROR`、`CANCELLED`、`INTERRUPTED`。成功与未确认都会锁屏，并尽力清理目标应用后台进程。
- 每轮失败发一封进度邮件，最终结果再发一封；主题与正文均为英文，前缀 `[Helper]`。
- “防移动监测”页可布防，被拿起或搬动时发邮件提醒；默认使用唤醒型显著运动与倾斜传感器，可勾选低频加速度兜底。

## 实现要点

- 两个 `AlarmManager.setAlarmClock()` 逐日安排，触发后只排该时段次日；延迟超 5 分钟记 `MISSED`，不补跑。
- 任务期间使用 `specialUse` 前台服务与 WakeLock，结束即释放；CPU 锁有 800 秒异常保护。
- 日志在私有目录 `files/logs/YYYY-MM-DD.jsonl`，保留 30 天；界面最多显示 500 条。
- 邮件经系统 JobScheduler 发送（smtp.qq.com:465 隐式 TLS），失败最多 5 次、最长 24 小时；授权码用 Android Keystore 加密保存，设置页防截图。
- 通知标题为 `Helper`，渠道 `General` / `Background`，锁屏不显示内容。
